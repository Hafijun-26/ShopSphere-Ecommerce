
🛍️ ShopSphere – E-Commerce Frontend

ShopSphere is a responsive e-commerce frontend application built using React, JavaScript, and CSS. It provides a simple shopping experience with product browsing, sorting, cart management, and a demo checkout flow.

✨ Features

- 🛒 Product listing with product images and prices
- ↕️ Sort products by price
- 🛍️ Add and remove products from the shopping cart
- 💾 Cart data persistence using Local Storage
- 📱 Responsive design for desktop and mobile devices
- 💳 Demo checkout flow with order confirmation
- 🎨 Clean and user-friendly interface

🛠️ Technologies Used

- React
- JavaScript
- HTML5
- CSS3
- Vite
- Browser Local Storage

🚀 Getting Started

Prerequisites

- Node.js
- npm

Installation

1. Clone the repository:
   
   git clone https://github.com/Hafijun-26/ShopSphere-Ecommerce.git

2. Navigate to the project folder:
   
   cd ShopSphere-Ecommerce

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL shown in your terminal.

📝 Note

This project currently focuses on the frontend. The checkout flow is for demonstration purposes only; real payment processing and backend integration are not connected.
